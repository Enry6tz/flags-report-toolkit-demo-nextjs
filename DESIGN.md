# Integration workspace visual system
This operational extension inherits the existing e6tz landing identity, without its alternate pixel world or decorative motion.
## Tokens
- Paper #f5f0e5; ink #2d2238; accent #f28c6e; muted #66596c.
- Surface #fffaf0; secondary surface #e9e0d7; line #d5ccca; focus #9a421f.
- UI typography: system sans with tuned weights and tabular numerals. Product operate mode prioritizes readability over display lettering.
- Space scale: 4, 8, 12, 16, 24, 32, 48 pixels. Border radius 12px for panels, 6px for controls.
## Structure
One quiet left navigation, a task header and contextual list/detail workspace. Mobile navigation becomes a horizontal, wrapping row; list/detail stacks. No fixed-height content traps.
## State language
Coral identifies the selected task and primary creation action. Real error/empty/loading states have explicit text and recovery, never status by color alone.
## Motion
No decorative animation. Native interaction feedback only; reduced-motion preferences are respected.
