# e6tz integration workspace
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Next.js App Router and React, explicitly selected by the user. Browser localStorage is the reference persistence adapter.
## Users
Developers evaluating and integrating the three public e6tz libraries into an existing host application.
## Product Purpose
A working Reports inbox, QA recording library and Flags menu in one local reference host.
## Capabilities and Constraints
Use the actual published libraries. No accounts, remote backend, shared database or production-security claims. Store reference-host records in the current browser. Explain the real backend replacement seams. New repository creation/publication is deferred to the user.
## Brand Commitments
Inherit the existing e6tz cream/ink/coral identity, sober and operational. No organic/pixel switch or decorative animation. User explicitly authorized implementation without additional design choices.
## Product Principles
- Real SDK interfaces, no mock capability claims.
- Browser-local persistence is explicit and recoverable on errors.
- Keep each integration independent and replaceable.
## Open Decisions
Production backend framework, database, authentication provider and remote deployment are not selected.
